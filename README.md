# SNL Stats

An ESPN-style, data driven, full-stack website made by a fan of Saturday Night Live for fans of Saturday Night Live! SNL Stats is a comprehensive website showing several statistics related to recent cast members of Saturday Night Live, including screen time, how many sketches they were in, their "power ranking", and the number of times they have said "LIVE FROM NEW YORK, IT'S SATURDAY NIGHT!". 

Users can view states episode-by-episode, season-by-season, and even explore the stats of different versions of the show (i.e. UK version). 

# Tech Stack

Next.js 16 / React 19 / TypeScript / Tailwind CSS / tRPC / Prisma / PostgreSQL (Supabase) / Recharts / Chart.js / Vercel
